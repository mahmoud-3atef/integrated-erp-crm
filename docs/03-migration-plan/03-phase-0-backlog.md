# 03 — قائمة مهام المرحلة 0 (التأسيس)

> الهدف: أساس شغال على سيرفر الاختبار — دخول بحساب الـ AD + MFA، إعدادات أساسية، محرك اعتماد، تدقيق، واجهة RTL، ومزامنة قراءة من الـ CRM.
> كل مهمة = شريحة صغيرة بتتجرب لوحدها. الترتيب مقصود.

| # | الشريحة | المحتوى | معيار القبول |
|---|---|---|---|
| 0.1 | **الـ Solution والمعايير** | هيكل `src/` (BuildingBlocks، SharedKernel، Modules، Hosts، Web)، .NET 10، تنسيق الكود، Architecture tests لحدود الموديولات، README للتشغيل | `dotnet build` و `dotnet test` ناجحين، واختبار حدود الموديولات بيفشل لو موديول لمس schema غيره |
| 0.2 | **القاعدة والترحيلات** | SQL Server (Dev محلي)، EF Core migrations لكل موديول بـ schema منفصل، جدول الإعدادات بتاريخ سريان | قاعدة جديدة بتتعمل من الصفر بأمر واحد |
| 0.3 | **البنية المشتركة** | **تعدد المستأجرين (`tenant_id` + فلتر EF + RLS)**، التدقيق (Audit)، تعدد السجلات (`legal_entity`)، الترقيم بدون فجوات، `Money`/`date`/التوقيت، الأكواد والقوائم بالترجمة، الأخطاء الموحدة، Outbox | اختبارات: ترقيم متوازي بدون تكرار/فجوات، التدقيق بيسجل قبل/بعد |

| 0.6 | **المنشأة والإعدادات** | السجلات التجارية (Care-Pro 05 و 07)، الفروع، القوائم المرجعية (المهن، الجنسيات، أسباب الرجيع… بأكواد)، سجل الموديولات | إضافة/تعديل من الشاشات مع التدقيق |
| 0.7 | **المستندات والإشعارات** | تخزين ملفات (واجهة S3-compatible — مجلد/MinIO)، المرفقات على أي سجل، إشعارات داخل النظام + إيميل | رفع مرفق وتحميله بالصلاحية؛ إشعار يوصل |
| 0.8 | **محرك الاعتماد** | Elsa 3 + خدمة الاعتماد الموحدة: تعريف مسار بمراحل ومسؤولين (مستخدم/دور/المدير المباشر/مدير المشروع)، مهامي، موافقة/رفض/إرجاع، الإصدارات | مستند تجريبي يمشي على مسار متعرّف من الشاشة |
| 0.9 | **المزامنة من الـ CRM (قراءة)** | Job بيسحب الكيانات المطلوبة للمرحلة 1 (`new_employee`, `new_project`, `account`, `new_empwork`, `mw_lodginorderdetails`, `hr_vicrequest`, `new_deliverorder`, السكن، `systemuser`, `team`) لـ `staging` تزايديًا بـ `modifiedon` | سحب كامل + تزايدي ناجح، ومفيش أي كتابة على `Care_Pro_MSCRM` (حساب قراءة فقط) |
| 0.10 | **النشر والتشغيل** | سكربت نشر لسيرفر الاختبار (IIS أو خدمة Windows)، الإعدادات بالبيئة، الأسرار خارج الملفات، السجلات (Serilog) والمراقبة الأساسية، Health checks، CI (build + tests) | نشر بأمر واحد، والنظام شغال على سيرفر الاختبار |

## اللي محتاجه منك عشان نبدأ 0.1
- **مستودع GitHub خاص** على حساب `mahmoud-3atef` (مثلًا `integrated-erp-crm`) — إنت تعمله فاضي من GitHub وأنا أربطه وأرفع عليه.
- **SQL Server للتطوير:** موجود بالفعل **LocalDB (SQL Server 2025)** على الجهاز ده — هنستخدمه للتطوير بـ compatibility level 160 (2022) عشان مانستخدمش مزايا مش موجودة في 2022؛ والـ Test/Prod على SQL Server 2022.
- باقي المتطلبات (حساب LDAP، سيرفر الاختبار) قبل الشريحة 0.4 و 0.10.
